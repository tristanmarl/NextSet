NextSet 0.4.3 makes the buttons simpler on the set screen, based on feedback on 0.4.1. BACK now steps back in time and there is no menu to open during a workout.

## BACK steps back in time

- **Set screen → BACK → the last set you logged for that exercise → BACK → the Overview → BACK → the Finish review.** An exercise with no set logged goes straight to the Overview.
- The last set opens with its weight and reps (a timed set: the time), titled **Set N** (**Warmup N** while only warmups are logged). UP/DOWN pick a field, START edits it, BACK restores it. **BACK from the choice saves what you changed** (nothing if you changed nothing) and shows the Overview.
- A new last row, **Delete**, asks **Delete set N?** (**Keep** is selected first). Delete takes you back to the set screen with that set open again.

## Change weight and Add set

- **Hold UP on the set screen is Change weight** (for a timed set **Change time**): UP/DOWN change it, START saves, BACK cancels. Bodyweight sets have nothing to change, so they show no hold-UP icon. The one-time hint still reads "Hold UP: change weight".
- **Hold UP on the Overview adds a set** to the shown exercise, with a short buzz. At the set limit it says "Max sets reached".
- The hold-UP menu is gone: Edit last set, Delete set, Add set, Skip warmups, Skip rest, Log paused set, Reopen exercise and Finish workout no longer exist as menu items. A running timer is paused with BACK and resumed with START; Change time resets it.
- If an older version closed an exercise early, START on it in the Overview reopens it.

## Finish workout

- **BACK on the Overview opens the review**: START saves, BACK asks **Keep working** or **Discard**, with the same fonts as the review. With no set logged the review still opens (START says "Log a set before saving"), so you can discard an empty workout.

## Weight step and exercises

- The "Weight step" menu is gone. The step is **automatic: 2.5 kg or 5 lb**. Liftosaur's data has no rounding value NextSet could follow. Weight steps you set in an earlier version are still applied; routines synced earlier get the new 2.5 kg step.
- **Skip exercise** and **Replace exercise** are gone. Follow the program, or finish the workout early.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

## Not yet confirmed on a real watch

The new button flow was checked in the simulator (Forerunner 965 and fenix 7S) and by unit tests, but not yet on a real watch. Reports are welcome; see [docs/DEVICE_TESTS.md](https://github.com/tristanmarl/NextSet/blob/main/docs/DEVICE_TESTS.md) and open an issue with your watch model.
