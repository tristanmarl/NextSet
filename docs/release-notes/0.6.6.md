NextSet 0.6.6 fixes Test key and sync on the fenix 7 and fenix 8.

- **Fixes Test key and sync on the fenix 7 and fenix 8.** Every request failed with "Request failed · CIQ -200" (invalid request header), on Bluetooth and on watch Wi-Fi alike. NextSet sent a `Content-Type` header as text on every request; these watches reject that before sending anything, while the Forerunner 965 accepted it. GET requests (Test key, sync) now send no `Content-Type`, and uploads send it in the form Garmin documents.
- **Test key no longer waits forever.** If no answer arrives within 60 seconds it shows "No response after 60 s" instead of "Testing".

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

If Test key or sync still fails, please report the message with its code (see [error codes](../ERROR_CODES.md)), the line from Settings → Diagnostics and your watch model.
