NextSet 0.6.0 follows Liftosaur programs more closely, syncs with less memory and makes problems easier to report.

- **AMRAP sets show "3+".** Sets marked as many-reps-as-possible in Liftosaur (`1x3+`, `1x12+`) show their reps with a "+" on the set screen, the exercise list and the routine preview, so you remember to enter what you really did. Programs that progress on extra AMRAP reps now get them. Logging is still one START press.
- **Rest per set.** Each set keeps its own rest time from Liftosaur (`3x5 20s, 2x5 120s` rests 20 s, then 120 s). Before, every set used the first set's rest.
- **Forerunner 255 sync crash.** Garmin's crash reports showed NextSet being stopped for running too long while syncing a heavy day. A day is now handled in four short steps instead of one long one and checked once instead of three times. Tested in the simulator; reports from a real Forerunner 255 are welcome.
- **Leaner sync.** The memory peak during a sync is much lower: replies are converted and dropped before anything is saved, only the current week is kept, and saves no longer read old copies back. If memory is still too low, the sync stops with "Low memory · retry sync" instead of crashing.
- **Diagnostics you can paste.** Home → hold UP → Settings → Diagnostics now starts with one line for bug reports: app version, watch, the step NextSet was in if it stopped unexpectedly last time, and why the last sync failed. Long text wraps and scrolls with UP/DOWN. A failed sync says "Sync failed: Settings > Diagnostics".
- Fixed a crash when a sync reply arrived after the sync had already moved on.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

When reporting a problem, please include the Diagnostics line and, for a sync problem, your program's Liftosaur share link (liftosaur.com/p/…).

---

NextSet is an unofficial companion app, not made or endorsed by Liftosaur or Garmin. It needs Liftosaur Premium for API access.
