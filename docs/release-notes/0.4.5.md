NextSet 0.4.5 finishes a workout like a native Garmin activity and lets you sync to Liftosaur from the summary.

- **Resume / Save / Discard.** BACK on the Overview (or Home during a workout) opens one screen: Resume (selected first), Save, Discard. BACK resumes. Discard asks "Discard workout?" before it throws the workout away. Save with no set logged says "Log a set before saving".
- **The hold-UP icon shows what it changes:** a dumbbell on the set screen (Change weight), a clock for a timed set (Change time). The Overview keeps the plus.
- **"START: Sync to Liftosaur" on the summary** while the upload is waiting or failed. The Liftosaur row shows an arrow while uploading, a check when done, a short red error on failure. START exits once it is uploaded.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

---

NextSet is an unofficial companion app, not made or endorsed by Liftosaur or Garmin. It needs Liftosaur Premium for API access.
