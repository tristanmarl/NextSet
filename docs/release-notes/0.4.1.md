NextSet 0.4.1 makes the watch fully button-operated and gives set editing a clearer flow, based on feedback on 0.4.0.

## Buttons only

- **Touch is ignored everywhere in NextSet.** A sweaty wrist or a brush against the screen can no longer select the weight, log a set or confirm anything. (Garmin's own system menus, such as the hold-UP menu, are unchanged.)
- On the set screen **UP/DOWN always change the reps** (the duration on a timed set) and **START logs the set**, one press per set as before. The reps are yellow and underlined as the value you are changing.

## Edit set

- Hold UP and choose **Edit set** (the first item) to change the next set, or **Edit last set** to fix the one you just logged.
- The weight and reps are shown big. UP/DOWN pick a field (the weight is selected first), START enters it and it turns yellow and underlined, UP/DOWN change it (fast presses speed up the weight), START keeps it and BACK puts the old value back. BACK from the field choice saves and closes.
- Bodyweight sets edit the reps only, timed sets the duration. "Change load" and "Change reps" are gone, and a one-time hint on the set screen reads "Hold UP: edit set".

## Overview and set dots

- The **Overview** now fills the screen: exercise name, "Exercise 2/8", the sets done big ("2/3"), the next set ("55 kg × 9") and your heart rate.
- **Set dots are bigger and clearer:** done sets are green, open sets have a light-gray outline, the current set is white with a ring. With more than six sets the screen shows "4/8" instead of dots.

## Fixes

- "Starting workout…" was cut off on small watches. The messages are now "Starting…", "Saving…" and "Cancelling…", and they wrap instead of being cut. After a failed save, START retries.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

## Not yet confirmed on a real watch

The new editor, touch being ignored and the new Overview were checked in the simulator (Forerunner 965 and fenix 7S) and by unit tests, but not yet on a real watch. Reports are welcome; see [docs/DEVICE_TESTS.md](https://github.com/tristanmarl/NextSet/blob/main/docs/DEVICE_TESTS.md) and open an issue with your watch model.
