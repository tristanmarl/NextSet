NextSet 0.4.2 simplifies finishing a workout and changing the weight, based on feedback on 0.4.1.

## Finish workout

- **Finish workout is the last item of the hold-UP menu.** The "Workout…" submenu and "Cancel workout" are gone. The item opens the review: START saves, BACK asks **Keep working** or **Discard**. The choice now uses the same fonts as the review, so it feels like one flow instead of a jump from Garmin's menu to a different-looking screen.
- With no set logged the review still opens (START says "Log a set before saving"), so you can discard an empty workout. BACK on the Overview opens the review too.

## Change weight

- The first item of the hold-UP menu is **Change weight** (for a timed set **Change time**; bodyweight sets have none, their reps change on the set screen). It opens the weight on its own, yellow and underlined: UP/DOWN change it (fast presses speed up), **START saves and closes**, **BACK closes without saving**.
- **Edit last set** keeps the two-field editor from 0.4.1.
- The one-time hint on the set screen reads "Hold UP: change weight".

## Weight step

- The "Weight step" menu is gone. The step is **automatic: 2.5 kg or 5 lb**. Liftosaur's data has no rounding value NextSet could follow. Weight steps you set in an earlier version are still applied; routines synced earlier get the new 2.5 kg step.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

## Not yet confirmed on a real watch

The new menus and editor were checked in the simulator (Forerunner 965 and fenix 7S) and by unit tests, but not yet on a real watch. Reports are welcome; see [docs/DEVICE_TESTS.md](https://github.com/tristanmarl/NextSet/blob/main/docs/DEVICE_TESTS.md) and open an issue with your watch model.
