NextSet 0.6.4 keeps a day on the watch when one of its exercises has no sets.

- **An exercise with no sets no longer hides the whole day.** If a program line has no set count (for example `Back Extension / 35s+|60s` instead of `Back Extension / 1x1 35s+|60s`), Liftosaur sends that exercise with no sets. NextSet skipped the whole day ("no sets"), so it was missing on the watch. Now only that exercise is left out, the rest of the day syncs, and Settings → Diagnostics says which exercise was left out ("W1 D2 Back Extension: no sets, left out"). To get the exercise back, add a set count to the line in Liftosaur (`1x1 35s+|60s` for a timed hold).

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept. After updating, run Sync routines once.

When reporting a problem, please include the line from Settings → Diagnostics and, for a sync problem, your program's Liftosaur share link (liftosaur.com/p/…).
