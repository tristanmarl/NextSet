NextSet 0.6.5 shows the error code when Test key or a sync fails, so connection problems can be tracked down.

- **Connection errors name their cause.** "No connection" (Settings → Test key) and "Could not reach Liftosaur" (sync) were catch-all messages: they appeared for timeouts, replies the phone could not pass on and unexpected server answers alike, and said nothing about which. They now show the code:
  - Test key: "No response · CIQ -300" (timeout or dropped link, worth retrying) or "Request failed · HTTP 404" / "Request failed · CIQ -400" (anything else).
  - Sync: the Home screen shows "Sync failed · CIQ -400", and Settings → Diagnostics keeps it as "Last sync: Request failed: CIQ -400" until the next successful sync.
  - "HTTP n" is Liftosaur's answer, "CIQ n" an error from the watch or the Garmin Connect app. A wrong key or an account without Premium still reads "Key rejected"; no phone link still reads "Phone not connected".

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

If Test key or sync fails, please report the message with its code, the line from Settings → Diagnostics, your watch model and whether your phone is an iPhone or Android.
