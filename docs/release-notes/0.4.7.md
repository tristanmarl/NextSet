NextSet 0.4.7 gives the exercise list the same set dots as the set screen.

- **Set dots on the exercise list.** The Overview shows the dots row for the shown exercise (warmups as small gray dots, then the sets) instead of the big "2/3 sets"; "Exercise 2/8" sits below it and the next set ("55 kg × 9") is a little larger.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

---

NextSet is an unofficial companion app, not made or endorsed by Liftosaur or Garmin. It needs Liftosaur Premium for API access.

## Connect IQ Store

```
Set progress is always dots, warmups included, on the set screen, during the rest and now on the exercise list.
BACK on the set screen opens the last set with a Continue row, so an accidental BACK costs one START.
```
