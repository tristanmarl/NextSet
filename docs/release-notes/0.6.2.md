NextSet 0.6.2 makes routine sync and workout upload more reliable.

- **Days without a weight no longer disappear.** When the program gives a set no weight (for example `Pull Up / 3x8`), NextSet skipped the whole day, so only the other days of the week were on the watch. Such sets now count as bodyweight sets.
- **Faster, simpler routine sync.** NextSet no longer downloads and reads your whole program text. It asks Liftosaur for each day of the current week directly and uses Liftosaur's own day names. This also removes a crash on the Forerunner 255 while reading long programs ("code executed too long").
- **Uploads recover from a bad connection.** Server errors, timeouts and temporary Bluetooth errors now retry later instead of stopping the upload for good.
- **Same exercise twice in a day.** When one day has the same exercise twice with different labels (`heavy: Squat` and `light: Squat`), both now upload to the right exercise in Liftosaur; before, their sets were left out.
- **Weighted holds** (a timed set with a weight) upload their planned weight instead of 0 kg, and very long finish notes are shortened so Liftosaur accepts them.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept. After updating, run Sync routines once.

When reporting a problem, please include the line from Settings → Diagnostics and, for a sync problem, your program's Liftosaur share link (liftosaur.com/p/…).
