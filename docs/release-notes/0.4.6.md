NextSet 0.4.6 adds a way to simply continue after BACK on the set screen.

- **Continue in the last-set editor.** BACK on the set screen opens the last set you logged with a new first row, **Continue**, already selected. START on it saves any change and returns to the set screen, so an accidental BACK costs one press (BACK, then START). Weight, reps and Delete work as before; BACK still saves and goes to the Overview.
- **The set dots stay visible during the rest,** with the rest time below them.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.
