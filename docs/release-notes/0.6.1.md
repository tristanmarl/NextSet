NextSet 0.6.1 fixes syncing programs that have more than one week.

- **Multi-week programs sync again.** For a program with several weeks, Liftosaur names each day after its week and day ("Week 7 - Day 1"), while the program text only says "## Day 1". NextSet saw these as different days and stopped the sync with "day name differs from API". It now accepts both forms, so 12-week, 16-week and other multi-week programs sync. Long week and day names (up to 128 bytes together) are allowed too.

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept. After updating, run Sync routines once.

When reporting a problem, please include the line from Settings → Diagnostics and, for a sync problem, your program's Liftosaur share link (liftosaur.com/p/…).
