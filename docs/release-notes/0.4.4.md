NextSet 0.4.4 makes the hold-UP button easier to find.

- The hold-UP icon now sits right beside the **UP** button instead of next to LIGHT.
- It is drawn in an open ring, which signals "hold": dots on the set screen (hold UP to change the weight), a plus on the Overview (hold UP to add a set).

## Install

Install or update NextSet from the **Connect IQ Store** (search for "NextSet"). Your workouts and settings are kept.

---

NextSet is an unofficial companion app, not made or endorsed by Liftosaur or Garmin. It needs Liftosaur Premium for API access.
